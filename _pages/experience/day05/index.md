Day 05 从展平图像的 MLP 走向卷积网络。主线是先看懂图像的空间结构，再逐层核对 Shape，最后复用已有训练流程完成 FashionMNIST 分类。

## 图像为什么适合卷积

灰度图批次的形状是 `[B,1,28,28]`。MLP 先将每张图展成 784 个数；CNN 则在展平之前，使用小卷积核读取局部区域，并把同一组参数用于不同位置。这对应局部连接和权重共享。随着层数增加，一个位置能间接利用更大范围的原图信息，即感受野扩大。

卷积层的权重排列为 `[输出通道,输入通道,核高,核宽]`，其中没有 batch 维。以 `Conv2d(1,32,3,padding=1)` 为例，输入 `[B,1,28,28]`，输出 `[B,32,28,28]`。每个输出通道是一张中间 Feature Map；它不是原图的简单复制。

## 逐层核对 Shape

```text
[B,1,28,28]
 → Conv(1→32, 3×3, padding=1) → [B,32,28,28]
 → MaxPool(2)                → [B,32,14,14]
 → Conv(32→64, 3×3, padding=1) → [B,64,14,14]
 → MaxPool(2)                → [B,64,7,7]
 → Flatten                  → [B,3136]
 → Linear(3136→128)         → [B,128]
 → Linear(128→10)           → [B,10]
```

实际逐层打印与手算一致。`3×3` 卷积使用 `stride=1,padding=1` 时保持高宽；此处 `MaxPool2d(2)` 将高宽减半；`flatten(start_dim=1)` 只展开单个样本的特征，保留 batch。网络总计 **421,642** 个可训练参数，其中第一层全连接层占 **401,536** 个。这说明使用卷积并不意味着整个模型参数一定少。

## 训练与比较

在相近的 FashionMNIST 三轮训练设置下，CNN 最后一轮训练准确率为 **91.01%**，评估准确率为 **89.69%**；重新运行的 MLP 分别为 **87.82%** 和 **86.52%**。这两次运行的评估差为 **3.17 个百分点**。CNN 另一次运行的最终评估准确率为 **90.41%**，提醒我们随机初始化和数据顺序会带来波动。

这个比较能支持“当前设置下 CNN 的结果更高”，却不能证明差距只来自卷积结构：两个模型的参数量不同，也没有控制随机种子。训练脚本把评估指标称作 `Val Acc`，实际使用的是 FashionMNIST 官方测试集，并未另划验证集。更规范的实验应保留独立测试集作最终评估。

## Feature Map 的观察边界

单张图像从 `[1,28,28]` 加上 batch 维后，经首层卷积得到 `[1,32,28,28]`；不同输出通道显示不同数值分布。这次使用的是**随机初始化**的卷积层，因此只能说明不同核会产生不同响应，还不能给通道贴上“已学会某类衣物特征”的标签。下一步可用训练后的卷积层重新观察。
